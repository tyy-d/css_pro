# Original starter submissions

Six clearly titled “Starter” code designs, prepared from original CSS Pro source. JPEG covers were captured directly from the exact HTML/CSS in `designs.json` at an 800 × 640 CSS-pixel viewport, with no external resources. These are static visual starters, not functional music players, forms or analytics applications. Text and CSS are MIT licensed under the repository policy.

These files are not community records yet and are not attributed to a placeholder account. After verifying the owner's Auth ID and hosted project, `scripts/import-starters.mjs` can create private drafts using that owner's ordinary bearer token. It uses the same validated upload/save/publish APIs as the interface; it does not bypass ownership with a service key. Its default creates drafts. `--publish` explicitly publishes all six after review. Already published starter IDs are skipped. Never commit or paste owner tokens into chat.

To recapture after any source change, serve each design's HTML/CSS locally as a complete document, capture it with the browser at 800 × 640, inspect the output, and replace its corresponding JPEG. Never edit only the screenshot or claim an illustration matches different source.
